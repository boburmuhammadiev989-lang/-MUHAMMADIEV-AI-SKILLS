# SEO and analytics

## SEO workflow
- Research search intent and audience language.
- Create useful, original pages with descriptive titles, headings, metadata, and internal links.
- Ensure crawlability, canonical URLs, sitemap, robots rules, mobile usability, and sensible page speed.
- Add structured data only when it accurately describes visible page content.
- Monitor indexing and search performance; do not promise rankings.

## Analytics workflow
- Define measurable events tied to product goals.
- Use consistent event names and document properties.
- Avoid collecting sensitive personal data unnecessarily.
- Respect consent and applicable privacy requirements.
- Review funnels, retention, acquisition, and conversion quality; distinguish correlation from causation.
