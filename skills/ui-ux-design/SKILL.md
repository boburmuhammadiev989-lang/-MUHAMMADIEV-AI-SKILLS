# UI/UX and design systems

## Process
1. Understand user goals, tasks, constraints, and context.
2. Map information architecture and critical user journeys.
3. Establish tokens for color, typography, spacing, radius, elevation, and motion.
4. Design reusable components and clear interaction states.
5. Prioritize mobile ergonomics, readable hierarchy, and accessible contrast.
6. Include empty, loading, error, success, disabled, and permission-denied states.
7. Validate with realistic content, long labels, localization, and RTL where needed.
8. Test key flows with users or structured task walkthroughs; record observed friction.

## Principles
Use visual hierarchy rather than decoration. Keep primary actions obvious. Do not use color alone to communicate status. Respect reduced-motion preferences. Avoid dark patterns and misleading subscription flows.
