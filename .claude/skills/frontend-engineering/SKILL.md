# Frontend engineering

## Workflow
1. Inspect framework, routing, package versions, styling conventions, and component structure.
2. Reuse existing patterns and design tokens; avoid unnecessary dependencies.
3. Define component boundaries and state ownership before implementation.
4. Build semantic, keyboard-accessible forms and controls with labels and visible focus states.
5. Handle loading, empty, success, validation, and failure states.
6. Make layouts responsive from narrow mobile screens upward.
7. Verify language switching, long strings, font fallback, and RTL direction where required.
8. Run available lint, typecheck, unit, and build commands.

## Review checklist
No dead buttons, clipped content, inaccessible contrast, missing labels, uncontrolled layout shifts, console errors, or broken navigation. Avoid arbitrary fixed widths and duplicated state. Do not claim tests passed unless run.
