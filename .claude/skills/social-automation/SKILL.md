# Social automation

## Workflow
1. Define channels, supported events, permitted API scopes, and account ownership.
2. Use official platform APIs and approved integrations; verify current policies and permissions.
3. Trigger only on clear user intent or consent. Provide opt-out and a human support path.
4. Keep replies grounded in an approved knowledge base; say when information is unknown.
5. Avoid spam, unsolicited bulk DMs, deceptive engagement, scraping private data, or evading platform limits.
6. Store the minimum conversation data needed, define retention, and restrict access.
7. Add rate limits, duplicate-event handling, retries, audit logs, and escalation.
8. Test keyword edge cases, multilingual messages, abuse, outages, and revoked permissions.

## Safety
Never ask for passwords or one-time login codes. Do not send messages or publish content without the account owner's authorization.
